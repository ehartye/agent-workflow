## Bounded evidence review

Mine only authorized retained evidence: start with exact run/report identity and version, then bounded status, activity, diff or exclusion-inventory pages relevant to the failing stage. Record data instance/runtime, generation, position and cumulative attempt when observed, plus event/page/report identity. Follow retained cursors within the declared review bound; disclose truncation, absent fields and unexamined pages. Do not dump whole histories or infer missing predecessor bytes from JSON.

Classify each observation against the current architecture: **shipped** means an implemented invariant with a named regression owner; **open** means a remaining behavior or evidence gap; **superseded** means the historical implementation no longer applies. Extend the existing invariant's coverage before adding another test. A new production correction needs a failing public/process/persistence reproducer, a falsifiable acceptance check and reviewed fresh verification; useful recovered files do not establish successful execution or authenticated acceptance.
