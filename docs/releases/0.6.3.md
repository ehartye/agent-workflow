# Agent Workflow 0.6.3

An unchanged caller can use its exact prepared runtime even when another session selects a different package version or source fingerprint. Selection verifies full caller version/source/Node identity and source/native/dependency integrity without rewriting the shared pointer, history or saved runs. Missing or invalid matches fail before dispatch; nothing installs, repairs or falls back automatically.

CLI errors and doctor distinguish missing and invalid nondefault matches with bounded identities. The already matching current installation retains its existing verification categories. Saved runs keep their recorded runtime, exact Node and session rules. Older immutable launchers retain their original code and behavior.

See [the runtime-selection contract](../runtime-selection.md), [design](../superpowers/specs/2026-10-24-package-runtime-selection-design.md), [plan](../superpowers/plans/2026-10-24-package-runtime-selection.md) and [verification](../verification.md). Qualification and publication receipts belong to [the release](https://github.com/ehartye/agent-workflow/releases/tag/v0.6.3). This change does not create a stable external launcher or serialize simultaneous setup operations.
