# 0.4.0 candidate

This is a source candidate. Publication, marketplace selection and owner installation require separate evidence. Version 0.3.6 remains the installed release while this candidate is verified.

New workers default to unbounded wall time; explicit positive safe-integer budgets remain available. CLI deadline controls use the exact session, generation, worker, attempt, turn and revision to set, extend or clear a live budget without another model request. Startup, command, protocol, interruption, evaluator and cleanup limits remain separate. Pause waits for accepted work; Stop retains bounded cancellation and honest unknown outcomes. Earlier runs keep their recorded runtime and original defaults.

It cannot grant new access, create dependencies or silently repeat uncertain effects. Admission receipts, physical origins and source positions survive replay; all saved readers preserve uncertain dispatch and one coherent SQLite snapshot.

Consumer-owned observation receipts record processed cursors, gaps and terminal basis separately from execution data. They do not establish host chat delivery or unrestricted command-body retention.

Authoring guidance requires genuine per-role skill selection, complete owned artifacts, coordinator capture review, fresh verification and explicit recovery. Historical evaluation failures remain retained. The fresh full-artifact comparison is a separate acceptance stage; one pair cannot prove general skill efficacy or automatic triggering.
