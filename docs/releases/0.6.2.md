# Agent Workflow 0.6.2

Inert `plan` output now exposes `resultBudget` on recognized agent call sites. Literal schemas use the dispatch compiler's exact serialized JSON allowance, so authors can size outputs before worker startup. Dynamic expressions and inspection limits remain unknown; invalid literal schemas retain their compiler error code. The preview executes no workflow code and does not grant dispatch admission.

Setup help now lists `setup` and `doctor [--cwd path]` separately. Setup remains independent of a project working directory. Existing `validate --summary` reports exact source identity and declaration counts, with full output available without that flag.

See [the API](../api.md), [inspection limits](../roadmap-command-contracts.md#inert-result-budget-inspection), [design](../superpowers/specs/2026-10-24-validation-preview-design.md) and [verification record](../verification.md). Local release receipts and hosted tag verification belong to [the release](https://github.com/ehartye/agent-workflow/releases/tag/v0.6.2). Earlier runs keep their recorded runtime and behavior.
