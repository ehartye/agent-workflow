Local evidence is in `reports/foundation-local-acceptance.json`. The six-stage probe used no inference. The two-thread check used two model turns, each with one successful command, in overlapping lifetimes (about 9.6 and 12.6 seconds). It proves local worker command execution, not arbitrary tree drain, a hard shared model budget or full product parity. SSH is deliberately deferred by the owner.

The fresh `engine/` slice passed two managed-ChatGPT file reads and completed-prefix replay with dispatch counts `[2, 0]`; see `reports/engine-local-acceptance.json`. Independent review and regression tests cover timeout identity, inherited external tools and corrupt persistence. The owner explicitly selected no custom MCP integration; CLI and dashboard are the intended surfaces. This evidence does not establish full parity or replace the installed plugin.

The native interruption check observed a real command startup marker, interrupted its model turn, and successfully reused the retained server for a command-only request. No command-completion item arrived. `reports/foundation-interruption-acceptance.json` therefore proves protocol interruption while retaining unverified descendant state; it does not establish safe restart.

The detached controller uses a generation/session-bound SQLite mailbox for pause/stop. It closes admission before acknowledging controls, drains active work, and records terminal state only after shutdown. Launcher abandonment before commit dispatches no workers. Stop shortens an existing pause deadline; every accepted control is settled before mailbox closure. Interrupted workers with uncertain effects remain blocked.

Native background acceptance passed pause, saved-script resume and completed replay with attempts `[1,2,2]` and cached results `[0,1,2]`; each generation recorded normal owned-server exit. See `reports/background-local-acceptance.json`. The checkpoint passes 192 tests, package check and smoke, with independent review. An earlier observation failed although the persisted run paused successfully; its cause remains unknown.

The fresh monitor uses bounded coherent SQLite snapshots, a bearer-authenticated loopback URL and generation-bound control/detail requests. Optional `id`/`dependsOn` declarations enforce real prerequisite scheduling and persist graph edges; grouping and undeclared dependencies remain distinct. Light/dark and mobile rendering were inspected with explicit simulated workers, not presented as native execution evidence. The graph's percentage uses discovered work, not an invented fixed total.

Structured acceptance in `reports/structured-local-acceptance.json` passed a real successful command, exact JSON marker, effective model/reasoning/permissions and normal owned-server exits, then replayed with dispatch counts `[1,0]`. Deterministic tests cover same-thread correction, shared lifetime reservations, bounded validation, known-invalid versus unknown outcomes and settings-sensitive cache reuse. Schema admission detects supported contradictions, not arbitrary logical unsatisfiability.

Live activity acceptance in `reports/activity-local-acceptance.json` verifies persisted command startup before completion, 59 retained native events, token totals and zero-dispatch replay. The authenticated inspector exposes bounded paged history with explicit truncation/discard counts; raw reasoning is excluded. Review regressions cover terminal callback races, rollback leakage and corrupt coverage counters.

Individual controls acceptance in `reports/individual-controls-local-acceptance.json` demonstrates two real workers: steering and cancellation are applied to one exact attempt, its sibling remains active and returns the expected marker, and both owned Windows jobs reach zero. The cancelled outcome remains unknown until explicit effect reconciliation. The per-worker App Server and retained-handle job host replace the shared worker lifetime boundary. The source review established that native ACK/inventory alone cannot prove job drain; the new `jobEmpty` evidence is scoped to Windows job members, not externally brokered processes or effects. Earlier experimental reports with a broader descendants label are superseded by this reviewed contract. Native terminal cleanup failure still blocks replay. Offline review regressions also cover immediate queued cancellation and isolation of mutable transport errors.

Next implementation gate: safe restart with explicit reconciliation and retained history, then isolated writable workspaces, saved workflows and plugin distribution.
