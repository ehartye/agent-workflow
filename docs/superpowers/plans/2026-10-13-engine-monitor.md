# Connect the monitor to the fresh engine

Continue the authorized parity rebuild with a single-run local monitor. The owner selected no MCP and requested Beautiful with agent-marketing as visual reference. The UI reads current SQLite evidence, displays ordered workers and phases, and invokes only existing pause, stop and saved-script resume controls. No legacy runtime imports, native calls during inspection, automatic retry or migration.

Use a loopback HTTP server with a random bearer token delivered in the URL fragment, removed before API requests and retained in tab session storage. Validate Host, Origin, method, body size and generation. Static assets have a strict self-only CSP. A dedicated hidden detached monitor process serves a single explicit run; it expires after inactivity and never owns worker termination. New dashboard invocations create independent views, not duplicate workflows.

Routine polling returns bounded previews, coverage and explicit truncation; full worker, script and result evidence loads only on deliberate disclosure. Read one coherent SQLite transaction per snapshot. Paused/completed known runs may resume; unknown workers, stale ownership, runtime mismatch and failed cleanup retain existing rejection. Resume checks generation again under the controller's exclusive lock to prevent delayed requests from replaying a newer generation.
