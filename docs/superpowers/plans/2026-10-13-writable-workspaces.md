# Isolated writable workers

Execute part 3 of the approved worker-parity release specification. Keep the installed runtime separate. Writer authorization is an explicit run permission ceiling; workflow options may narrow it, never broaden it. Each writer receives a unique sibling Git worktree under `<main-repository>-worktrees`, retained after success or interruption. No automatic merge, deletion or uncertain-workspace reuse.

Capture the source HEAD and current permitted local inputs before dispatch. Read regular tracked and nonignored untracked files, preserving exact bytes; refuse symlinks, submodules, conflicts, escaping paths and oversized captures. Use a private Git index to build an input tree without changing the source index. Create detached worktrees without checkout and populate captured bytes, avoiding checkout filters and hooks. Record source/base/input identity outside the worker writable root. Worker-only and base-relative binary patches must include new files and remain readable after interruption. Snapshot and patch collection must not execute repository-defined diff drivers or filters.

The native backend must confirm workspace-write, no network, never approvals, and precisely the owned workspace roots. Disable implicit temporary-directory writable grants. Recheck effective project configuration and disabled integrations for each worker cwd. Probe actual in-scope writes and denied source/sibling/metadata writes with command-only requests before relying on model execution. Retained Windows job ownership remains the cleanup boundary. Workspace files are retained even if termination or artifact collection is uncertain; errors are evidence, not permission to discard them.

Expose workspace identity and bounded diff summary on worker records. CLI and authenticated monitor deliberately read immutable patches by current generation/worker identity; paths supplied by callers never select arbitrary files. Replay requires intact artifacts and retained workspace evidence. Restart uses a fresh workspace from the captured run inputs and keeps old workspace references in prior execution history.
